# The 2.5D depth interpreter — pinned.
#
# WHY A SECOND INTERPRETER AT ALL
# DepthFlow's renderer imports `typing.Self`, which needs Python 3.11+, and
# the pipeline's own venv is 3.10. So the 2.5D path runs under
# `<worktree>/.venv-depth` and nothing else does.
#
# WHY THE PATH IS PER-WORKTREE, AND WHY THIS FILE EXISTS
# `DEPTH_PY = ROOT / ".venv-depth" / "bin" / "python"` in
# scripts/build_25d_cuts.py and lib/verify_depth_parallax.py is relative to
# the worktree that runs it. On 2026-11-09 it existed ONLY in OpenMontage,
# so the runner — which is what makes the films — had no way to build a 2.5D
# cut at all. This file is how any worktree gets the same one.
#
#   uv venv --python 3.12 .venv-depth
#   uv pip install --python .venv-depth/bin/python -r requirements-depth.txt
#
# FULLY PINNED, not just the direct dependencies: a renderer whose output is
# compared frame-to-frame against a gate cannot be allowed to drift with
# whatever a resolver picks on the day.
#
# The MODEL WEIGHTS are not here. Depth Anything V2 Small lives in
# ~/.cache/huggingface, which is user-level and shared by every worktree.
